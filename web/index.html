Maintenance

Export XMP sidecars

Write captions, keywords and named faces where Lightroom and digiKam can read them. Originals are never touched.

Import XMP sidecars

Read keywords and ratings from existing .xmp files. Added as your own tags; captions and faces are left alone.

Prune missing photos

Drop photos with no readable copy left anywhere. Files on a disconnected drive count as offline, not missing, and are kept.

Remove duplicate faces

Detection used to add a second copy of every face you had named or ignored each time it re-ran, so people appear twice on a photo and dismissed strangers come back. This clears the copies. Nothing you named or ignored is touched.

Retry failed work

Failures are usually a drive that was unplugged or a model server that was down. This puts them back in the queue.
